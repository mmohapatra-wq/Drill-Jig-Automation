! ============================================================================
! Datum CSYS at the INTERSECTION of 3 perpendicular planes  (operator's mapkey)
! ----------------------------------------------------------------------------
! Recorded 2026-07-13. This is the recipe csysinator.cmd / drilljig STAGE 5 /
! drilljig-gui.cmd's Index stage replay (by tree-search select-by-ID instead of the
! model-tree AssyTree node paths below - see lib\drilljig_core.ps1
! Build-CsysFromPlanesMacro).
!
! WHAT IT DOES: select 3 mutually-perpendicular planes (X-normal, Y-normal,
! Z-normal), then create a datum coordinate system at their common point. The
! 3 planes fully define the origin (their intersection) AND the orientation, so
! there are NO mouse picks and NO orientation tab - unlike the older
! origin-edge + orientation-plane flow (docs\csys_from_round_edge.mapkey.txt),
! which that older csysinator used and which is now SCRAPPED.
!
! This is the exact analog of the proven 3-plane-intersection DATUM POINT recipe
! (Build-IntersectPointMacro -> ProCmdDatumPointGeneral): the same
! accumulate-3-planes selection, with ProCmdDatumCsys instead of the point command.
!
! In drilljig, every drilled hole's point was built from exactly such a triple
! [SIDE-face, X-plane(from TOP), Z-plane(from FRONT)]; STAGE 5 lets you pick a hole
! and re-uses its triple to drop the index coordinate system there.
!
! The T3 10 / T3 6 / T3 13 tokens below are model-tree node labels from the
! operator's part; the tools instead feed the 3 plane feature IDs via the proven
! tree-search select-by-ID (accumulating). The last two lines show the new csys.
! ============================================================================
mapkey yes @MAPKEY_LABELyes;\
mapkey(continued) ~ Select `main_dlg_cur` `PHTLeft.AssyTree` 1 `T3 10`;\
mapkey(continued) ~ Select `main_dlg_cur` `PHTLeft.AssyTree` 2 `T3 10` `T3 6`  2;\
mapkey(continued) ~ Select `main_dlg_cur` `PHTLeft.AssyTree` 3 `T3 10` `T3 6` `T3 13`  2;\
mapkey(continued) ~ Command `ProCmdDatumCsys` ;~ Activate `Odui_Dlg_00` `stdbtn_1`;\
mapkey(continued) ~ Select `main_dlg_cur` `PHTLeft.AssyTree` 1 `T3 52`;\
mapkey(continued) ~ Command `ProCmdViewShow@PopupMenuTree`;
