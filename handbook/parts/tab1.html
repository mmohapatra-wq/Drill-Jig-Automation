The flat drill-jig wizard (drilljig-gui) walks you screen-by-screen from a blank jig part to a fully drilled, chip-relieved guide plate. It automates a live Creo session for the geometry-build steps, while doing all the layout math and 2D/3D previews itself. This tab is the operator manual: every button, every stage, every prompt.

This zip is the .cmd launcher plus all resources — 11 PowerShell libs, bushing catalogs, the decision tree, the WebGL preview page, vendored three.js v0.160.0, and the WebView2 SDK (x64). No network access, scavenges nothing.

The zip is self-contained, but it cannot ship these — they must already be present on the workstation:

2. Quick start

  1. Extract the folder anywhere writable (Desktop or Documents — not a locked/protected path).
  2. Open Creo and open the jig PART (.prt, not .asm).
  3. Double-click drilljig-gui.cmd.
  4. Walk the wizard: Welcome → Import → Bushing → Layout → Overview → Datums → Box → Drill → Relief → Done.

3. The window at a glance

The wizard opens maximized. There are three regions:

TOP — breadcrumb rail

10 stage pills: Welcome, Import, Bushing, Layout, Overview, Datums, Box, Drill, Relief, Done.

  • Done = green check
  • Active = blue halo
  • Future = hollow

The rail is clickable: click a pill to jump back to any stage you have already reached. You can never skip ahead past setup you have not done.

CENTER — canvas

Swaps per step; scrolls if a step is tall. This is where the choice cards, editors, and previews live.

BOTTOM — controls

An honesty-chip band (status chips) + the Back / primary-button bar + a status line.

While Creo work runs, the canvas flips to a RUN view (progress marquee + live log) and all input is disabled (a busy guard) so a stray click cannot re-enter Creo.

4. The buttons — global rules

This is the heart of the tab. Four kinds of controls, plus the in-canvas prompts:

PRIMARY button right, blue

Its label changes per step (Get started / Next / Continue to datums / Create planes + open sketcher / Finish + extrude / Drill the holes / Open the seed sketch / Finish the seed slot / Finish).

Disabled until the step's condition is met — a bushing length chosen, a valid number typed, or a required Creo pick verified. Clicking it may run blocking Creo work (the RUN view appears).

BACK button left, slate w/ blue border

Labelled ‹ Back. Shown and enabled on every page except the first (Welcome), where there is nowhere to go.

Back is free — no confirmation dialog. Going Back never undoes Creo geometry; RUN steps are idempotent on re-entry and show an “already built” banner, so you can safely step back to re-read or change an earlier choice. (See §6 for exactly when to use it.)

BREADCRUMB pills

Click any already-reached stage to jump straight to it. Cannot jump forward past unfinished setup.

CHOICE CARDS

Large clickable tiles. A green border marks the selected/preselected card, and every card lights green on hover so you always see the outline of the box you are about to pick.

Most cards act immediately when clicked (they re-render to drill deeper — e.g. the bushing tree — or advance).

Exception: Layout tiles are radio-select
Clicking a Layout tile only moves the green highlight. You press NEXT to commit the highlighted choice.
In-canvas prompts (Yes / No / OK)
These appear as an overlay inside the wizard window — never a separate popup that could hide behind Creo.

6. When (and how) to go back

The wizard is built for “change anything at any point.” There are several backward moves, each for a different need — and going back never deletes Creo geometry, so it is always safe to look.

Once the plate is built, real geometry exists. You can still go Back (RUN steps are idempotent and show an “already built” banner), but re-editing an earlier value does not resize the already-built plate — e.g. the slot depth is frozen into the plate’s pad at build time, and the slot-depth step then shows a “plate already built — re-run to change” note. To truly change a committed dimension, close and re-run the wizard (or edit the dimension in Creo).

7. The bushing selection, in depth

The Bushing stage is a short decision walk that ends by resolving two numbers: the drilled hole diameter and the bushing length. What the walk shows you depends on two answers — material and drill method, because those decide which kind of bushing the jig is built around.

The two bushing types

Sleeve (press-fit liner)

A hardened sleeve is permanently pressed into the jig; the drill runs through its bore. Selection keys on the ID (the bore that guides the drill); the jig hole is bored to the sleeve’s OD. From data/bushings.csv.

Used by: Metal → PFD, and both 3D-print methods.

Removable drill bushing

A slip bushing that drops into the jig plate; the plate hole IS the bushing’s OD (the bore ID doesn’t matter to the plate). Selection keys on the OD, and only 1/2″ and 3/4″ ODs are offered. From data/bushings_drill.csv.

Used by: Metal → Hand drill.

How material × drill method changes the options

MaterialDrill methodCatalog you getKeyed onSizes offered
MetalPFD (power-feed drill)SleevesID3/4 ID
MetalHand drillRemovable drill bushingsOD (= the drilled hole)1/2, 3/4 OD
3D printPFDSleevesID1/2, 3/4 ID
3D printHand drillSleevesID1/2, 3/4 ID

PFD = power-feed drill (portable / power-feed); Hand drill = manual. Only Metal → Hand drill takes the OD-first removable path (it shows OD cards and skips the ID question, because the plate hole is the bushing OD). Every hole-size list also carries a trailing “Custom hole OD…” card — type any diameter and the tool shows a bold “verify a real bushing exists” warning, since no catalog SKU backs a typed size. And the material choice echoes later: 3D-print jigs auto-add chip-relief slots, while metal jigs are asked.

The walk, screen by screen

Click any screenshot to enlarge. The exact middle screens depend on your material × method answers (OD cards vs ID cards).

The walk then ends in a confirmation card (the picked bushing, its part number, and a dimensioned schematic) — shown as step 3 in the reference below.

The recommended length, and moving inside the walk

Bushing lengths are standardized to the bore/OD (a 1/2 is normally 1/2″ long, a 3/4 is 3/4″), so the matching length card is pre-highlighted green — just press Next to take it, or click a different card / Custom… to type your own.

Inside the walk, the compact ‹ Back undoes one answer at a time, and Start over restarts from the material question — so if you realize the wrong material or drill method gave you the wrong bushing type, you can back up to exactly that card. (More on going back in §6.)

Stage: Bushing
“Next”

Sets the wall from a border hole’s edge to the plate edge, which drives how big the plate is. Standard margin keeps one full hole diameter of wall on every side; Smaller margin lets you type a tighter wall (it seeds one hole radius as a sensible starting value and shows an editable field). A Change button re-opens the choice.

What you do

Creo pick
No.
5
Chip-relief slot depth
Stage: Bushing
“Next”

Sets the chip-relief slot depth, which does double duty as the plate’s extrude pad: the plate is built to bushing length + slot depth, then the slot removes exactly the slot depth — so the finished guide depth always equals the bushing length. A smaller slot depth therefore yields a thinner overall plate, useful for tight spaces. Launching with --slot-depth pins the value and skips this screen; --no-slot-relief leaves the depth unused.

Enabled when
Once a mode is set; the Tight option needs a valid depth > 0.
Default preselect
Standard clearance = 0.25″.
What you do
Pick Standard clearance, or Tight / restricted space and type a (usually smaller) depth.
Creo pick
No.

How are the hole points defined?
Stage: Layout
“Next”

Chooses where the hole points come from, via four tiles: Skeleton Model (datum points already in the part — you pick them later), Orthogrid Model (a regular N×N grid), User Generated Model (type each hole’s X/Z), and Fastener-Driven Model (an existing part’s fastener pattern). Picking Orthogrid or User-Generated opens an inline editor with a live preview and an X/Z slot-direction toggle right in the window; Change layout type returns to the tiles.

Default preselect

“Next”

Chooses which hole is the index — the origin the whole jig’s coordinate system is referenced from. An index is always set (default is the corner hole); the cards let you pick a different one. Building the base coordinate system at the index hole up front is the geometry-preserving way to reference it (nothing is moved later). This screen self-skips for the Skeleton/predefined layout.

10
Build the parametric box
Stage: Box
“Create planes + open sketcher”

The first half of building the plate. The tool asks once (a Yes/No overlay) whether to add chip-relief slots — which pads the plate — then computes the three offset-plane distances (SIDE = bushing length + relief pad, TOP = plate width, FRONT = plate height), creates those offset planes, and opens Creo’s sketcher for you. It is tool-driven: don’t touch Creo while it runs.

Enabled when
Always.
Default preselect
None (the Yes/No relief prompt appears on Next).
What you do
Press the button; answer the relief prompt.
Creo pick
Tool-driven — planes + sketcher open automatically.
11
Finish the box commit point
Stage: Box
“Finish + extrude”

The commit point. With the sketcher open, you draw the plate rectangle using Creo’s snap-to-intersection trick, then the tool finishes the sketch and extrudes to the SIDE plane. Real geometry now exists; you can still go Back afterward, but the plate stays built (§6).

  1. Hold Ctrl+Alt and click the two shown planes (the offset planes just created). The corner snaps to their intersection — dotted blue reference lines appear.
  2. Drag the rectangle from that snapped corner to the opposite corner.
  3. Press Esc, then click Finish + extrude.
Enabled when
Once the planes + sketcher are armed.
Default preselect
None.

Yes — manual rectangle draw (see the snap diagram below).

15
Chip-relief slots: cut + pattern
Stage: Relief
“Finish the seed slot”

You draw one seed rectangle over the first hole row; the tool cuts it, then patterns that slot onto every remaining row hands-free. The first cut is verify/flip-checked — it asks “Did the slot cut in at the right depth?” and can flip the direction + reopen the sketcher if not (it may also ask you to re-select the seed cut in the model tree if auto-reselect misses).

  1. Hold Ctrl+Alt and click the two shown references (the row line / face edges) so the corner snaps.
  2. Drag the seed rectangle over the first hole row.
  3. Press Esc, then click Finish the seed slot; confirm the direction if asked.
Enabled when
Once the seed is armed (or slots were skipped).
Creo pick
Yes — draw the seed + confirm direction (same snap trick as the box; see diagram).

Done
Stage: Done
“Finish”

A summary of everything built, with honest warnings where they apply — e.g. if the plate was padded for relief that wasn’t actually cut, it tells you the guide is oversized and how to fix it. Finish closes the wizard; your Creo session stays open. Always eyeball the geometry in Creo before trusting it.

Enabled when
Always.
Default preselect
None.
What you do
Read the summary, press Finish, verify in Creo.
Creo pick
No.
The two moments you must draw in Creo
  1. Box rectangle (step 11) — hold Ctrl+Alt, click the two shown planes to snap the corner to their intersection, drag corner-to-corner, Esc.
  2. Seed slot (step 15) — same snap trick: Ctrl+Alt-click the shown references, drag ONE rectangle over the first hole row, Esc, confirm direction; the rest pattern automatically.
Everything else the tool does itself.

9. Command-line flags (optional)

Pass these to drilljig-gui.cmd to override defaults or skip questions:

FlagEffect
--no-corner-roundSkip the corner round.
--corner-radius NCorner radius (default 0.25).
--slot-depth NSlot depth in inches (default 0.25); pads the plate; skips the slot-depth question.
--no-slot-reliefSkip slots entirely.
--slot-flipFlip seed-slot direction.
--pattern-flipFlip pattern direction.
--no-patternDraw every slot row by hand instead of patterning.

SymptomFix
“Creo (xtop.exe) is not running”Open Creo + the jig part; keep exactly one session.
“VB API registration not found”Register the VB API from Creo’s install — run vb_api_register.bat from \Parametric\bin as Administrator.
3D preview shows a plain noteWebView2 Evergreen Runtime is missing/old; the wizard, math, and the WPF bushing preview are unaffected.
“active model is an ASSEMBLY”Open the jig PART (.prt), not the .asm.
Wizard seems stuckSwitch to Creo — it may be waiting for a pick or a manual draw. Check the RUN log / PowerShell window.
A step “did nothing”The canary aborted a macro that changed no geometry rather than claim false success; check the reported reason (a pick wasn't armed, a widget drifted, or the wrong model/body was active).
