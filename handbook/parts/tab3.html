Every tool in the toolkit besides the flat drill-jig wizard lives here. If you just want the whole thing, grab the complete repo below and keep the folder structure intact. Individual scripts are listed further down for grabbing or inspecting one file at a time.

Read before downloading single scripts

The complete toolkit zip contains everything: pipeline\, tools\, previews\, probes\, the shared lib\, data\ catalogs, docs\, and the CLAUDE.md / DEV_NOTES.md / MAPKEYS.md reference. Extract it and keep the folder structure — each .cmd re-anchors $ScriptDir to the repo root so lib\, data\ and docs\ resolve.

The individual per-tool buttons below are for grabbing or inspecting one script. A lone .cmd still needs the toolkit's lib\ + data\ + docs\ beside it to run.

Pipeline — end-to-end flow + bushing selector

The production flows that chain the primitives together, plus the standalone bushing selector that feeds them.

ToolWhat it does
Flat drill-jig CONSOLE flow — bushing pick → parametric box → corner round → datum points → On-Point drilling → chip-relief slots in one connect/build/drill/slot pass. Supports all four point modes. Flags: --slot-depth N, --slot-dir X|Z, --slot-face, --corner-radius N, --no-corner-round, --no-base-csys, --fastener-index.
Curved / conformal CONSOLE flow — pick a surface → offset (at a standoff) → thicken into a new body → optional On-Point holes normal to the surface → optional one chip-relief slot per hole. Flags: --no-tree, --tangent-orient, -defaultorient, --no-slots, --slot-depth N.
The curved / conformal WinForms WIZARD (analog of the flat GUI in Tab 1). Builds a CONFORMAL BLANK (offset + thicken of the picked surface) instead of a box. Requires the jig PART to be the ACTIVE model (Activate it inside a top-down assembly first). Stages: Welcome, Bushing, Surface, Fasteners, Relief, Done. See the Roadmap tab — several curved legs are canary-gated but unverified live.
The bushing SELECTOR on its own — walks the decision tree + bushing catalogs to recommend a bushing OD/ID/length (OD = the drilled jig-hole diameter), with an OD-first metal path and an ID-first sleeve path. Writes last_jig_spec.json as a handoff to the drilling tools.

Note: the FLAT wizard, drilljig-gui, is the download on the “Using the GUI” tab.

Standalone primitives (tools/)

Each proves ONE Creo capability in isolation; several are the building blocks the pipeline folds in.

ToolWhat it does
Rectangular extrude to exact L/W/H, measures the solid, and auto-corrects the depth dimension if it came out wrong — verified parametric geometry creation.
Auto-detects a plate's vertical corner edges and rounds them, with a manual-pick fallback.
Creates a datum coordinate system at the intersection of three selected planes, fed by ID.
Reads a CSV of dimensions BACK into a model (the read-back companion to gauginator), with a 2-pass verify/repair loop for sketch dims.
Reads fastener bore centers from an open part/assembly (cylinder-axis, the proven non-crashing read), projects to a 2D (X,Z) layout, and writes fastener_layout.json.
Batch selection capture and per-body flip/mirror redefine operations.
Whole-model traversal + dimension / mass-property extraction to CSV (the export half of the round-trip).
Interactive fastener/nut management in an assembly — filter valid HST fasteners, change diameter/grip with matching nuts, convert coatings to the grounding variant.
Creates a native On-Point hole at every selected datum point, each an atomic select-by-ID + hole-dashboard macro (canary-verifies hole #1 before committing the rest).
Read-only hole-pattern inspection — reads selected bore surfaces, projects to a tilt-safe 2D layout, analyses spacing/collision; writes hole_layout.json.
Copies a feature to many datum-point locations via Paste-Special by reference, rerouting each placement.
Cuts one connected chip-clearance pocket as a shallow blind remove-material extrude, offset inward from the plate boundary.
Pure-VB-API edge filtering (by length / curve type) feeding a batched round mapkey.
Cuts one blind rectangular chip-relief slot per hole row (seed drawn once, then patterned).
Creates surfaces by extruding selected 3D curves between datum planes.
Thickens selected surface quilts into solid bodies (the pattern reused by boxinator and the conformal blank).

Previews / visualizers (previews/)

No Creo needed; driven by the SAME production sources the live tools use (never a re-implementation).

ToolWhat it does
2D bushing schematic (GDI+), rendered from OD/ID/Length via lib\bushing_svg.ps1.
A selected bushing as both the 2D schematic and a live 3D model (WPF Media3D, hollow bore + head flange).
3D drill-jig plate with live sliders (WPF Media3D, ZERO external DLLs), dot-sourcing the real lib\orthogrid.ps1 so it matches production. The zero-dependency fallback renderer.
High-fidelity 3D jig hosting the approved docs\drilljig_3d_preview.html (WebView2 + three.js/WebGL) via lib\webview2_host.ps1.
