Roadmap

This tab collects candidate improvements, honestly labelled by status and effort. Items marked done are already implemented; everything else is a proposal. Where a step still needs a live Creo recording or a live probe to confirm the load-bearing assumption, it is called out explicitly. Nothing here is a promise of a ship date — it is a prioritized backlog.

Sourcing caveat
The numeric jig-design rules used below — edge margin, center distance, normality tolerance, press-fit interference, and 3-2-1 locating — are long-established jig-and-fixture practice (Hoffman, Jig and Fixture Design; ASME B94.33; vendor catalogs). They could not be re-verified live during the research run (WebSearch was down at the time; the only hard numbers that came through were from Carr Lane's “Understanding Standard Drill Bushing Types”). Treat every number below as an editable default, not a hard constant.

1. The curved / conformal jig (drilljig3d) — the biggest frontier

A curved jig can't be a flat plate. So instead of building a box, the 3D pipeline builds a conformal blank: it copies the part's curved face (offset surface / quilt), then thickens that into a new solid body that follows the curvature. The bushing holes are then driven normal to that surface rather than normal to a flat top.

Where it stands: STAGE 1 (offset-surface + thicken → new body, flipped away from the part) and STAGE 2 (On-Point holes normal-to-surface via surface pre-select) are confirmed working live (2026-06-24). The biggest open correctness question is simple to state and load-bearing: does pre-selecting the surface truly orient each hole normal to the face, or does Creo quietly fall back to its own default?

Already implemented

  • done Per-hole orientation surface (mode 2) — pairs each point with its own host surface.
  • done Hole-count + diameter blind-evaluator gate — counts cylinders at the target radius before and after; the delta must equal the intended count.
  • done Standoff / chip-clearance offset — default 0 = flush; a value >0 floats the jig off the part.
  • done Bushing-OD handoff pre-fill — reads last_jig_spec.json to pre-fill the seat diameter.
  • done Thickness-vs-bushing sanity guidance — soft-warns when a wall is too thin for the chosen bushing.

Bigger bets

Counterbore / bushing-seat (stepped bore)

What makes the jig actually hold a bushing: a counterbore at the bushing OD, depth = bushing length, over a smaller thru clearance hole.

Route B (a second coaxial On-Point hole at a blind depth) reuses Build-NormalHoleMacro and needs only a blind-depth flyout recording. Route A (a native counterbore profile) is cleaner geometry but its widgets are unrecorded.

Headed-bushing counterbore + catalog data layer

blocked on data, not code

HeadDia, HeadHeight, PressFitHoleDia, PressFitTol, and FitClass are not in either CSV — all seeded rows are slip / liner, zero headed. Add the columns from a vendor spec plus a press-fit interference offset (Carr Lane: 0.0005–0.0008″ headless, 0.0003–0.0005″ headed).

Locating / registration (3-2-1)

A conformal face alone leaves the jig free to slide and rotate. Locating-pin holes = a second labelled STAGE-2 pass at an independent diameter (zero new mapkeys).

Round-vs-diamond-pin and 3-2-1 layout stay design guidance the tool surfaces, not geometry it computes — keep it a human pick.

Auto-generate the hole grid on the curved face

highest risk

Bridge the flat orthogrid GUI + seed→pattern into the 3D tool. The hard part: an orthogonal X/Z grid doesn't map cleanly onto a curved face, and a Direction-pattern keeps direction, not per-member normality. Build-PointPatternMacro widgets are UNVERIFIED — keep Invoke-ManualPointGrid as the guaranteed path.

Stamp bushing identity as Creo parameters

Write BUSHING_PN / OD / ID / LEN / DRILL_SIZE so the jig self-documents.

The param-create API is unverified on this build — confirm live or fall back to a *_jig_spec.json sidecar.

Hole-axis-normal verification gate

High value, needs a live probe. For each drilled cylinder, read its axis (Get-CylinderAxes, confirmed) and compare to the local surface normal; apply a deterministic gate |dot(axis, normal)| >= cos(tol). This converts the currently-eyeballed normality claim into a measured one.

Blocked on the Eval3DData normal read being usable on this build (and on IpfcForeignSurface) — the --probe-orient item settles it. Pair it with a thru-all “broke through” gate via a GetMassProperty().Volume delta.

Open questions (settle before the dependent items)

  1. Does pre-selecting the surface orient the On-Point hole normal, or take Creo's default?
  2. Does IpfcSurface.Eval3DData(EvalParameters(p)).Normal return a usable normal on this build, including IpfcForeignSurface?
  3. Does an On-Point HOLE diameter dim hold a feature-level DimValue write, or snap back?
  4. Is .Volume readable on GetMassProperty($null)?
  5. Are headed / press-fit bushings actually in scope (the catalog has zero headed rows)?
Deliberately NOT recommended
Copy / Publish Geometry — a multi-model construct that conflicts with the .asm guard and the ID-only-against-active-model design. Wrap / Flatten Quilt — wrong direction: these map flat geometry onto a surface, not the inverse a conformal jig needs.

3. Cross-cutting ideas

  • Richer bushing catalog data (headed / press-fit rows, fit classes) to unlock counterbores.
  • Parameter-stamping the jig for traceability.
  • More probe-captured mapkeys, to move “unverified” legs to “verified”.
  • Extending the blind-evaluator gates to more stages, so “done” always means “measured”.
